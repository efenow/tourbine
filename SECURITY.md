# Security Policy

## Supported Versions

The following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| LATEST  | :white_check_mark: |

## Reporting a Vulnerability

Please use the [**Private Vulnerability Reporting System *(PVRS)***](https://github.com/efenow/tourbine/security/advisories/new), also known as Security Advisories, to report vulnerabilities. **Do not use issues to report a vulnerability!**
